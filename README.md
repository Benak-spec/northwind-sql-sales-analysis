# northwind-sql-sales-analysis
SQL analysis on the Northwind dataset using joins, aggregations, and window functions.

## Overview:
This project analyzes sales performance, customer behavior, and product trends using SQL on the Northwind dataset. The objective is to extract meaningful business insights such as revenue drivers, high-value customers, product performance, and sales trends over time.

## Tools Used:
- SQL (PostgreSQL)
- Northwind Dataset

## Key Business Questions
- What is the total revenue generated?
- Which products generate the most revenue?
- Who are the top customers by revenue?
- How many orders does each customer place?
- What are the monthly revenue trends?
- Which countries have the highest customer presence?
- Which products have never been ordered?
- How can customers be segmented based on revenue?
- Who are the top customers within each country?
- Which products perform best within each category?

## Key Insights
- A small number of customers contribute a significant portion of total revenue
- High-value products such as Côte de Blaye drive a large share of sales
- Revenue trends vary across months, indicating possible seasonality
- Customer segmentation reveals distinct high-value and low-value groups
- No products were left unordered, suggesting effective inventory utilization

## SQL Concepts Used
- Joins (INNER JOIN, LEFT JOIN)
- Aggregation (SUM, COUNT, AVG)
- Filtering (WHERE, HAVING)
- CASE statements (customer segmentation)
- Window Functions (RANK, PARTITION BY)
- Common Table Expressions (CTEs)

## Analysis
### 1. What is the total number of orders?
```sql
SELECT DISTINCT COUNT(order_id) FROM orders
```
**Insight:** 830 orders are present.

### 2. What is the total revenue generated?
```sql
SELECT SUM(order_details.unit_price * order_details.quantity * (1-order_details.discount)) AS total_revenue FROM order_details
```
**Insight:** 1265793.038653364 is the total revenue generated.

### 3. Show total revenue by product (with product name), sorted highest to lowest.
```sql
SELECT product_name,SUM(order_details.unit_price * order_details.quantity * (1-order_details.discount))
AS revenue_total FROM products INNER JOIN order_details
ON products.product_id = order_details.product_id
GROUP BY products.product_name
ORDER BY revenue_total DESC
```
**Insight:** This query is used to find the best selling product which is Côte de Blaye with a revenue of 141396.7356273254.

### 4. Show total revenue generated by each customer (with customer name), sorted highest to lowest.
```sql
SELECT customers.contact_name,SUM(order_details.unit_price * order_details.quantity * (1-order_details.discount))
AS total_revenue
FROM customers INNER JOIN orders
ON customers.customer_id = orders.customer_id INNER JOIN order_details
ON orders.order_id = order_details.order_id
GROUP BY customers.contact_name
ORDER BY total_revenue DESC
```
**Insight:** This analysis highlights the most revenue generated customers, in this case it is Horst Kloss with 110277.30503039382.

### 5. Show total number of orders placed by each customer, with customer name, sorted from highest to lowest.
```sql
SELECT COUNT(orders.order_id) AS total_orders,customers.contact_name FROM orders INNER JOIN customers
ON orders.customer_id = customers.customer_id
GROUP BY customers.contact_name
ORDER BY total_orders DESC
```
**Insight:** This query is used to find out how many orders each customer has placed from highest to lowest, in this case the highest orders are from Jose Pavarotti

### 6. Show the total revenue for each product category, with category name, sorted highest to lowest.
```sql
SELECT categories.category_name,products.category_id, SUM(order_details.unit_price * order_details.quantity * (1-discount))
AS total_revenue
FROM categories INNER JOIN products
ON categories.category_id = products.category_id INNER JOIN order_details
ON products.product_id = order_details.product_id
GROUP BY categories.category_name,products.category_id
ORDER BY total_revenue DESC
```
**Insight:** This query identifies which product category had the most generated revenue, which was beverages for us.

### 7. Show total revenue for each month, sorted by year and month.
```sql
SELECT TO_CHAR(orders.order_date,'YYYY-MM') AS order_month, SUM(order_details.unit_price * order_details.quantity * (1-order_details.discount)) 
AS total_revenue
FROM orders INNER JOIN order_details ON orders.order_id = order_details.order_id
GROUP BY TO_CHAR(orders.order_date,'YYYY-MM')
ORDER BY order_month
```
**Insight:** This code helps to find the sales trend over time.

### 8. Show the top 5 customers in the USA by total revenue, with company name.
```sql
SELECT SUM(order_details.unit_price * order_details.quantity * (1-order_details.discount)) AS revenue,
customers.company_name
FROM order_details INNER JOIN orders ON order_details.order_id = orders.order_id INNER JOIN customers
ON orders.customer_id = customers.customer_id
WHERE customers.country LIKE 'USA'
GROUP BY customers.company_name
ORDER BY revenue DESC
LIMIT 5
```
**Insight:** This code is used to return the top 5 customers in USA. 

### 9. Show countries with more than 5 customers.
```sql
SELECT country,COUNT (customer_id) FROM customers
GROUP BY country
HAVING COUNT(customer_id) > 5
```
**Insight:** Identifies countries with high customer presence.

### 10. Show average unit price for each product category.
```sql
SELECT AVG(order_details.unit_price) AS avg_price, categories.category_name 
FROM categories INNER JOIN products ON categories.category_id = products.category_id 
INNER JOIN order_details ON products.product_id = order_details.product_id
GROUP BY categories.category_name
```
**Insight:** Used to compare the prices among categories.

### 11. Classify customers based on total revenue
```sql
SELECT customers.contact_name, SUM(order_details.unit_price * order_details.quantity * (1-order_details.discount)) AS revenue,
CASE  
WHEN SUM(order_details.unit_price * order_details.quantity * (1-order_details.discount)) BETWEEN 1 AND 5000 THEN 'Cheapskates'
WHEN SUM(order_details.unit_price * order_details.quantity * (1-order_details.discount)) BETWEEN 5001 AND 10000 THEN 'Average Customers'
ELSE 'Top Customers'
END AS customer_priority
FROM order_details INNER JOIN orders ON order_details.order_id = orders.order_id INNER JOIN 
customers ON orders.customer_id = customers.customer_id
GROUP BY contact_name
ORDER BY customer_priority
```
**Insight:** Groups customers based on revenue.

### 12. Which products have never been ordered?
```sql
SELECT product_name FROM products LEFT OUTER JOIN order_details
ON products.product_id = order_details.product_id
WHERE order_details.product_id IS NULL
```
**Insight:** All products have been ordered, there are no products which have been left out.

### 13. Who are the top 3 customers by revenue in each country?
```sql
WITH customer_revenue AS (
SELECT SUM(order_details.unit_price * order_details.quantity * (1-order_details.discount)) AS revenue,
customers.country, customers.contact_name FROM order_details INNER JOIN orders
ON order_details.order_id = orders.order_id INNER JOIN customers 
ON orders.customer_id = customers.customer_id 
GROUP BY customers.country, customers.contact_name
),
ranked_customers AS (
SELECT country, contact_name, revenue, RANK() OVER(PARTITION BY country
ORDER BY revenue) AS customer_rank FROM customer_revenue
)
SELECT country, contact_name, revenue, customer_rank FROM ranked_customers
WHERE customer_rank <= 3
ORDER BY revenue,country DESC
```
**Insight:** I used this code to identify top 3 customers based on their country, which helps to identify better than overall top customers.

### 14. Show the top 2 products by revenue in each category
```sql
WITH product_revenue AS (
SELECT products.product_name, categories.category_name, SUM(order_details.unit_price * order_details.quantity *(1-order_details.discount)) AS revenue
FROM order_details INNER JOIN products ON order_details.product_id = products.product_id
INNER JOIN categories ON products.category_id = categories.category_id
GROUP BY categories.category_name, products.product_name
), ranked_products AS (
SELECT product_name, category_name, revenue, RANK() OVER(PARTITION BY category_name ORDER BY revenue DESC)
AS product_rank FROM product_revenue
)
SELECT product_name, category_name, revenue, product_rank FROM ranked_products
WHERE product_rank <= 2
ORDER BY revenue DESC
```
**Insight:** Helps to identify the top 2 performing products within each category, this helps to get the product from category instead of overall products.
